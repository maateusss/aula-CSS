Exemplo 32 - Exercicio de Aplicação de Classes

Instruções

Nesse exercicio voce devera praticar aplicações de clases CSS nos elementos HTML

utilize as classes disponiveis no arquivo estilos.css para modificar a aparencia dos textos abaixo.

voce devera experimentar as classes, destaque, cursiva, italico, sublinhado,azul, negrito, google.

lembre-se que e possivel utilizar mais de uma clase no mesmo elemento.

parte 1 - aplicando uma clase

o HTML e uma linguagem utilizada para criar a estrutura das paginas da internet.

O CSS e utilizado para definir a aparencia dos elementos, como cores, tamanhos e tipos de fonte.

parte 2 - utilizando mais de uma classe

As classes podem ser combinadas para criar diferentes efeitos visuais.

por exemplo, uma palavra pode ficar azul em negrito

outra palavra pode ficar sublinhado e italico

agora escolha outra palavra desse texto e aplique duas ou mais classes

parte 3 - Trabalho com fontes

a escolha da fonte pode alterar completamente a aparencia de um texto.

A classe Cursiva apresenta o texto com uma aparencia semelhante a escrita a mão.

A classe google possui uma fonte que pode ser personalizada pelo aluno no arquivo estilos.css.
